Analysis of the "IBM-HR-Employee-Attrition-Performance" dataset using both SQL and Python, with a Power BI dashboard.

Dataset - https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset

---

**About**
I wrote each query in only one language — whichever was more convenient. Every task has different syntax in SQL and Python, so I chose the one that was faster or easier to read.

---

**Stack**
*   **SQL (PostgreSQL)**
*   **Python**
*   **Power BI** — dashboard

---

**Structure**
*   `sql/` — SQL queries
*   `python/` — Python analysis
*   `power_bi/` — Power BI dashboard
